Menu 7 "Accessibility" with quick access

  • Menu item 7 is now "Accessibility": 7.1 Volume, 7.2 Speech output,

7.3 Camera.

  • 7.1 Volume: master, sound effects, music, ambience and dialog volume,

beacon volume, plus reverb, positional low-pass filter, DSP effects, sound in background and zone music no delay. These are shortcuts to the existing options and stay in sync both ways.

  • 7.2 Speech output: TTS voice, speed and volume.
  • 7.3 Camera: the former Video options menu (follow, zoom, etc.).
  • The original menus (Options/Options, Navigation/Options, Chat/Options)

remain unchanged.

  • After changing a value the cursor stays on that control (menu 7 only),

so several values can be set quickly.

Mailbox: focus stays on the letter

  • After taking gold or an item, the cursor stays on the letter instead of

jumping up to the inbox list. Press right-arrow to reopen the (updated) attachments and take more. When deleting, a neighbour letter is focused.

Navigation: "Data" menu item hidden

  • The "Data" item under Navigation is no longer shown.

Version

  • Sku.toc and SkuDispatcher/Sku.toc updated to v41.02.08.
