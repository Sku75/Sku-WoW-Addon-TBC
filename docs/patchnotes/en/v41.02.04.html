PageDown/PageUp in Sku menu corrected

  • PageDown/Up no longer jumps 10 menu entries in the Sku menu. The keys now only trigger scrolling in profession windows (recipe lists) and update the menu accordingly. In all other menus (bags, auction house, etc.) the keys have no effect.

Localization: Equipment sets

  • The menu entry "Ausruestungssets" in the character window was a hardcoded German string. It now uses L["Equipment sets"] and displays correctly as "Equipment sets" on English clients.

Localization: Socketing window

  • The frame name "Sockeln" on the first menu level was a hardcoded string. It now uses L["Sockeln"] and displays correctly as "Socket" on English clients.
