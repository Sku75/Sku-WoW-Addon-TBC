Sku TBC - Screen Reader Interface for World of Warcraft The Burning Crusade

Sku is a World of Warcraft addon that provides a complete screen reader interface, making the game accessible for blind and visually impaired players. It works with screen readers like NVDA and JAWS.

Automated Installation (recommended)

Sku Installer - Version 4.3

The Sku Installer is a small, screen-reader-friendly Windows program that does the whole addon setup for you: it finds your World of Warcraft folder, downloads Sku together with all required companion addons, copies everything into place, and switches on the game settings Sku needs. It also sets up the WoW Login Tool (see below) including its login-screen textures, fonts and the AutoHotkey runtime, and keeps it up to date on later runs. This is the easiest way to install or update Sku. When Windows asks, allow it to run as administrator.

The installer speaks English, German and French; it picks its language from Windows and you can change it at any time in the "Language of this installer" list.

Download Sku Installer (Windows)

You still need the game itself installed first, and sighted help once for the Battle.net login screens and the in-game license agreement — see the manual installation guide below for those steps.

The installer has its own version number, separate from the Sku addon version below. The download link above always gives you the newest installer, whichever Sku version is current.

Start Menu (Login Tool)

WoW Login Tool r2.0 (originally by Yennister)

Here is the current start menu tool. It helps with login, character creation, character selection and server selection. Version 2 reads the actual screen content (character names, realm lists and popups) out loud via OCR. Please read the included readme files. The automated installer above sets it up for you, including the required login-screen textures, fonts and the AutoHotkey runtime.

Download WoW Login Tool

Mapping Tool (for sighted mappers)

SkuMapper 5.0

A visible tool for sighted helpers to create and edit Sku map data (waypoints and routes). In game, open the map via the "Open Sku Minimap" keybinding (Key Bindings, "Other" category); import and export map data with /sku import and /sku export.

Download SkuMapper 5.0
