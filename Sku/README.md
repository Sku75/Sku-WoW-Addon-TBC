# Sku — WoW Screen Reader Addon (TBC)

Sku makes World of Warcraft accessible for blind and visually impaired players,
providing a complete screen-reader interface (NVDA / JAWS). This build targets
the Burning Crusade Classic Anniversary client (TBC 2.5.6 + Era 1.15.8).

- **Download & install page:** https://sku75.github.io/Sku-WoW-Addon-TBC/
- **Source & releases:** https://github.com/Sku75/Sku-WoW-Addon-TBC

## Help & documentation

- **How to play / standard key bindings** — see the
  `Readme - SkuAddon Standard Key Bindings for Blind Players` files in this
  folder (English, Deutsch, Français). They are also linked from the download
  page above.
- **Patch notes** — `Patch Notes Sku EN.txt` / `Patch Notes Sku DE.txt`.
- **Install guide** — on the download page (automated installer, plus a manual
  step-by-step guide in English and German).
