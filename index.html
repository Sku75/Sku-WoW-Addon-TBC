Sku TBC - Screen Reader Interface for World of Warcraft The Burning Crusade

Sku is a World of Warcraft addon that provides a complete screen reader interface, making the game accessible for blind and visually impaired players. It works with screen readers like NVDA and JAWS.

Notice: The addon versions on this page are for World of Warcraft – The Burning Crusade Anniversary Server.
Updating to a new version? You must replace all Sku addons in your WoW AddOns folder — not just the main addon. Download everything listed on this page and replace your existing files. Leaving old versions of Sku addons alongside a new one can cause errors.

Required Downloads

You need both of these addons to use Sku. Download and install them into your WoW AddOns folder.

Sku (Main Addon) - Version 41.07

The core addon that provides the screen reader interface.

Download Sku v41.07
