SkuAddon Standard Key Bindings for Blind Players

Here you will find the key bindings that are set when you reset the game and addon key bindings using the SkuAddon.
This is an overall recommendation. You are of course free to deviate from it.

Number row / Main action bar = Keys 1 to ´
Lower left action bar buttons 1 to 12 = F1 to F12 (must be assigned manually)

Target self = NUM1 + secondary binding e
Target group member 1 = NUM2 and secondary binding q
Group member 2 = NUM3
Group member 3 = NUM4
Group member 4 = NUM5
Follow target = NUM0 and secondary binding f
Assist target = NUM, and secondary binding r
Attack target = t - your character does not move
Interact with target = g - This also moves you towards the enemy or NPC. Can be used for attacking as well as interacting with quest givers or vendors etc.
Interact with object under mouse = Shift G
Target last target = h
To loot when the enemy is dead: H to target last target and then G to interact. You will receive the loot.

At higher levels you need more space for spells. The following key combinations should be added for additional action buttons on the side bars:
Right side bar buttons 1 to 12 = CTRL+ALT+F1 to F12

It is also recommended to use a keyboard with special keys such as the Logitech G15 keyboard, which has 18 programmable macro keys. You can assign the side bar key combinations to these keys. This way CTRL+ALT+F7 simply becomes a button in the second block (top left).

Using the key bindings:

You move with WASD. Nearby you will find all the keys to interact with your wingman / fellow player.

qf = Follow wingman
qr = Acquire wingman's target.
Q, R, G = Acquire wingman's target and attack (melee fighters run to the enemy and strike - ranged fighters turn towards the enemy and start running to attack. Then stop with S and begin casting.)

Interaction with NPC:
When you have the quest giver or vendor/trainer targeted, press G. Your character runs to them and the window opens.

Looting with wingman:
When your wingman provides you with a loot target (they target it for you), press qrg = target wingman, acquire target, interact with target.
G causes your character to run to the corpse and loot.

When placing spells on your action bars, you should establish a fixed structure. Ideally, the spells needed in combat should be placed in the F1 to F8 and number 1 to 7 range, as you can reach them quickly.
I have the same actions on keys 7 to ´ (acute symbol) on every character. These are: 7 drink, 8 eat, 9 hearthstone, 0 mana potion, ß health potion, ´ (acute) mount.

Additional addon functions and key bindings:

Shift and F1 opens the Sku menu
Shift and F2 opens the chat in reading mode. Arrow up and down to read lines. The first number announced is the chat line number.
F5 to F8 = Activate quick waypoint
Ctrl and Shift and F5 to F8 = Set quick waypoint to my position
Shift F9 = Show and activate waypoints in the area
Shift and F10 = Start route navigation - The first point announced is your entry point into the network. Press right arrow once and search for your destination using the filter. Press Enter to start the navigation guidance.
Shift F11 opens the action bar menu
Shift F12 ends navigation and a currently active beacon.
Ctrl and Shift and Z reverses the route navigation. The route now leads back to the starting point.
Ctrl and Shift and Y activates panic mode for fleeing. You cannot reach the sound. Run after it and you will be guided out of the danger zone. The path is the way you came.

Page Up and Down are only used in profession or trainer windows. They allow you to scroll through the recipe list.

If you quickly press Shift and Alt simultaneously, the compass direction you are facing will be announced.
AltGr tells you the direction and distance to the currently active audio beacon waypoint.

Ctrl and V is the silence key. You can use it to interrupt all voice output.

Ctrl and Shift and T =
When a roll window opens, you can use this to see what is being rolled on.
The item tooltip is displayed. You read it by holding only Shift after pressing Shift, Ctrl and T and then pressing arrow down.

Roll with Ctrl and Shift and X to pass, G for greed and B for need.
Ctrl and Shift and C repeats the announcement of what the roll is for (the short version).

NUM 6 = Target focus
CTRL and NUM 6 = Set focus - This focus can be friendly or hostile.
(You may need to set up the focus functions in the Sku key bindings first.)

Ctrl and NUM 1 to 5 = Set target markers.
CTRL NUM 0 = Remove target marker

NUM 7 = Right-click at your feet
NUM 8 = Right-click just in front of you.
NUM 9 = Turn towards the current audio beacon (approximately).

Num Lock on and off = Toggle auto-run on and off

Ctrl and W = Advance one beacon in route navigation
Ctrl and S = Go back one beacon.

Resource tracking:
If you have learned a profession that requires you to search for plants, ores or gases, you need to place the tracking skill on an action button and activate it by pressing it. After death it is usually deactivated again.
When the tracking is active, you will be notified when a resource appears on the minimap.
Then press Ctrl and F = Herb/Mining radar, trigger approx. 100-metre scan.
Ctrl and R = Precise herb/mining scan at approx. 50 metres
After the herb/mining scan, the found resources are announced with numbers. You can then activate them directly as a beacon using the quick waypoint keys (Shift F5 to F8).
Press Shift F5 for quick waypoint 1. This is also the first herb that was found. The quick waypoints are set to the locations.
You have to run in a straight line and hope you don't fall off anything.

Additional keys:
, (comma) = strafe left
. (period) = strafe right
Space bar = jump
L = Quest log
Y = Sheathe/draw weapon
X = Sit down or swim down or fly down
C = Character window
B = Open bags (close with ESC)
N = Open talent tree (from level 10)
M = Map - no function for us

Tab = Target next enemy
CTRL and Tab = Target next friend
Ctrl and Shift and Tab = Target next friend (including protected NPCs)
Enter opens and closes the chat

Soft targeting
Use soft targeting sparingly, as it also causes many disruptions.
Toggle the various soft target types on and off with:
Shift I = Soft target for enemies in front of you
Shift O = Soft target for objects you can interact with or NPCs you can talk to.
Shift P = Soft targeting for friendly players

The soft target announces what it sees. Press G to interact with it (loot, attack, talk etc.).
Active soft target functions can help, but it can also happen that you have an enemy targeted with Tab and want to attack it, while your soft target detects a different enemy. The soft target is sometimes given priority. The same applies when interacting with objects. If there is something to collect in front of you while you are fighting, the only solution is usually to move away from the collectible so that the soft target no longer detects it. It is best to only enable soft targets when you actually need them.
