# Sku addon — documentation index (LLM index)

Living, agent-readable map of the whole Sku (TBC Anniversary) addon plus its
real companion addons. Built in Workstream 6 Phase A against the finished
W1–W5 architecture. Two jobs: human-facing documentation, and the shared base
context every W6 cleanup agent reads so findings stay consistent and no agent
re-explores from scratch.

Each source file has one entry file under `index/<Module>/<File>.md` with a
fixed layout: Purpose, Public API / exports, Dependencies (outgoing), Key data
structures, Events, Settings keys, Entry points, Invariants & gotchas. This
INDEX.md is the top map; open a per-file entry for detail.

Keep this current: when Phase B moves or splits a file, regenerate this index
and update the affected entry file(s) before Phase C reads them.

## How the addon fits together (one-paragraph orientation)

Sku is an Ace3 addon. `Sku.toc` fixes the load order; `embeds.xml` pulls the
Ace3/LibStub stack. `Sku/Core.lua` creates the top `Sku` table and the voice-
pack scorer. Modules subscribe to game events through **SkuDispatcher** (the
central broker) rather than wiring WoW events directly. Settings go through the
**SkuSettings** facade over one AceDB SavedVariable; the whole screen-reader UI
is generated by the **SkuZOptions** menu framework (menu-item nodes with
`.next`/`.prev` sibling links, driven by keyboard). Speech flows through
`SkuOptions.Voice` (Libs/SkuVoice) which plays baked mp3 clips from a
`SkuAudioData*` voice pack or falls back to Blizzard TTS; audio-beacon
navigation runs on Libs/SkuBeacon with soundsets from the beacon companion
addons. `dprint` writes the `SkuDebugLog` ring; `SkuErrorLog` captures errors.

- [SkuCore/Core.lua](SkuCore/Core.md) — The heart of the SkuCore module (4400 lines).
- [SkuCore/damageMeter.lua](SkuCore/damageMeter.md) — Accessible bridge to the Details! damage meter addon — reads Details combat segments and renders DPS / total damage / damage-taken rankings as spoken menu tooltips, and auto-dismisses the Details welcome/assistant windows on login (they are unusable with a screen reader).

- [SkuCore/ErrorLog.lua](SkuCore/ErrorLog.md) — Standalone, dependency-free error-capture system.
- [SkuCore/friends.lua](SkuCore/friends.md) — The "Friends" feature — renders the WoW friend list, Battle.net friend list, ignore/who/guild placeholders as a Sku screen-reader menu ("Social" → Contacts).
- [SkuCore/gameOptions.lua](SkuCore/gameOptions.md) — Surfaces Blizzard's modern Settings panel (Escape → Options / "Spieloptionen") through Sku's own screen-reader menu, so a blind user can browse and change game settings without the inaccessible native panel.
- [SkuCore/gameWorldObjects.lua](SkuCore/gameWorldObjects.md) — The "camera sweep" world-object scanner: rotates the camera in horizontal/vertical steps while the mouse cursor is pinned to screen center, reads the GameTooltip under the cursor each frame, and voice-announces matches (lootable/skinnable corpses, creatures, quest objects, herbs, mining veins, fishing bobber, usable objects).

- [SkuCore/Macro.lua](SkuCore/Macro.md) — Accessible macro manager — a pure menu-builder feature that lets the user create, rename, delete, and list account/character macros through the Sku menu with text-entry EditBoxes instead of the inaccessible Blizzard macro UI.

- [SkuCore/minimapScanner.lua](SkuCore/minimapScanner.md) — Scans the minimap for gatherable resource blips (mining nodes, herbs, gas clouds) and announces them by voice with direction and distance, since a blind player cannot see the minimap dots.

- [SkuCore/Options.lua](SkuCore/Options.md) — The SkuCore module's options + menu-construction file, and (since W7) the builder of the whole top-level "Einstellungen" (Settings) menu.

- [SkuCore/turnToUnit.lua](SkuCore/turnToUnit.md) — "Turn to unit" feature — rotates the camera/character to face a chosen target (party member, raid marker, or Sku marker) using view-movement CVars and a search loop that watches mouseover/nameplate events until the target is acquired.
- [SkuCore/UIErrors.lua](SkuCore/UIErrors.md) — Turns Blizzard UI_ERROR_MESSAGE / UI_INFO_MESSAGE / spell-fail globals into short accessible feedback — either a category-specific error mp3 or a spoken message — so a blind player hears why an action failed (out of range, no line of sight, on cooldown, silenced, etc.).
- [SkuCore/updateCheck.lua](SkuCore/updateCheck.md) — Voice "a newer Sku is available" nudge without any internet access.
- [SkuCore/visualAids.lua](SkuCore/visualAids.md) — Opt-in visual aids for partially sighted players, all default-OFF: a reading bar (Lesebalken) showing the current menu item in large text, nameplate reaction colouring (enemy/neutral/friend), a mouse-finder flash (pulse ring or compass lines), a follow-break voice warning (AUTOFOLLOW_END), and a secure "next combat enemy" button (`/targetenemy`).
- [SkuCore/voiceOutput.lua](SkuCore/voiceOutput.md) — Small compatibility shim that keeps Blizzard's built-in TTS (`C_VoiceChat.SpeakText`) on the SAME audio output device as the rest of the game sound.

## SkuAuras — aura/buff/debuff tracking, role detection, sharing

- [SkuAuras/Core.lua](SkuAuras/Core.md) — The runtime engine of the SkuAuras module — a user-configurable "aura" system that watches combat-log events, unit health/power, cooldowns, weapon enchants, and keypresses, evaluates each saved aura's condition tree against the event, and fires audio/chat outputs.
- [SkuAuras/data.lua](SkuAuras/data.md) — The static "vocabulary" of the aura system — declarative tables that define every aura TYPE, ATTRIBUTE (with its per-attribute `evaluate` function and value list), OPERATOR (is/isNot/contains/bigger/…), ACTION (audio/chat/single variants), and OUTPUT (what gets spoken/printed when an aura fires).
- [SkuAuras/defaultAuras.lua](SkuAuras/defaultAuras.md) — Ships the built-in, ready-made aura "Sets" that users can apply from the "Aura Sets verwalten" menu (Options.lua).
- [SkuAuras/Options.lua](SkuAuras/Options.md) — The menu/UI layer of the aura system — builds the entire screen-reader "Auren" menu tree (create new aura step-by-step, manage/edit/rename/duplicate/delete existing auras, apply built-in aura sets, import/export).
- [SkuAuras/sharing.lua](SkuAuras/sharing.md) — Stage 1+2 of aura "Sets" sharing — named aura snapshots (with duplicate-name pruning) and group sharing over AceComm (hidden addon messages, auto-chunked).
